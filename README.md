# 工时记录器（WorkTimeRecorder）

macOS 状态栏工时记录器：解锁自动上班、达标锁屏自动下班、工时目标提醒、节假日缓存，以及日/周/月/季/年统计与 CSV 导出。全部数据只存在本机。

## 功能

1. **打卡**：手动打卡上下班；也可以自动——解锁电脑自动上班，工时达标后锁屏自动下班；下班记录支持撤销，用于回来加班继续计时。
2. **工时目标**：设置每日目标（默认 8 小时），可以为“今天”单独指定目标；状态栏与面板实时显示已工作多久、还差多久。
3. **达标提醒**：工时达标时发系统通知（屏幕右上角），提示可以下班。
4. **节假日**：每次启动自动从公开 API 拉取并缓存，也可以手动更新；离线时继续使用本地缓存。
5. **统计与导出**：周/月/季度/年度统计、加班时长、每日明细，导出打卡明细 CSV 与每日汇总 CSV。
6. **界面**：状态栏快速面板 + 工时分析窗口 + 设置窗口，浅色/深色外观自适应。
7. **Dock 与台前调度**：默认显示 Dock 图标、参与台前调度、Dock 右键可快速打卡；也可以在设置里勾选“隐藏 Dock 图标”，只保留状态栏。
8. **北京时间口径**：默认按北京时间（UTC+8）划分一天、显示时间并在数据文件中写入 `+08:00` 偏移的时间戳；可在设置里切换为跟随系统时区。

## 自动打卡规则（精确行为）

| 行为 | 触发条件 |
| --- | --- |
| 自动上班 | 开启自动上班，且当天在时间门槛（默认 04:00）之后**第一次解锁屏幕或从休眠唤醒**，同时当天**没有任何打卡记录**、当前不在上班状态 |
| 自动下班 | 开启自动下班，且**当天累计工时已达标**，此时**锁屏或休眠** |
| 撤销下班 | 当前不在上班状态，且最后一次打卡是下班（把该段恢复为“进行中”） |
| 达标提醒 | 正在上班且当天累计工时达标时，发送一次系统通知（每天最多一次） |

补充说明：

- 手动打过卡、或已经下班的日子，不会被自动上班打扰。
- 自动下班要求“达标 + 锁屏”同时满足；达标但没锁屏时会先发提醒，不会立刻打卡。
- 跨天连续工作按自然日裁剪：昨天的 22:00 到今天的 02:00 计为两天各 2 小时。
- 首次打卡时间可以修正：在状态栏面板的“今日记录”旁点“修正”，把当天第一次打卡改成实际上班时间（例如补录成 09:28）。

## 数据与隐私

- 数据文件：`~/Library/Application Support/WorkTimeRecorder/state.json`（原子写入；文件损坏时自动备份为 `state-corrupt-*.json` 并重新开始）。
- 时间戳：默认按北京时间（UTC+8）写入，例如 `2026-09-15T09:28:00+08:00`；旧版本以 UTC（`Z`）写入的文件仍可正常读取与迁移。
- 联网范围：仅节假日 API（`holiday-cn`，失败回退 `Nager.Date`），其余功能完全离线。
- 导出：CSV 带 UTF-8 BOM，Excel / Numbers 可直接打开；明细导出每段打卡，汇总导出按天统计。

## 构建与运行

要求：macOS 13+，Swift 6 工具链（Command Line Tools 或 Xcode 均可）。

```bash
swift build                          # 编译
swift test                           # 运行核心逻辑测试
swift run WorkTimeRecorder           # 直接运行（开发模式）
swift run WorkTimeRecorder --demo    # 用内存演示数据预览界面，不写入磁盘
./scripts/build_app.sh               # 打包 dist/WorkTimeRecorder.app
open dist/WorkTimeRecorder.app       # 启动（建议把 .app 拖进 /Applications）
```

说明：

- 直接 `swift run` 时进程没有 bundle identifier，系统通知会被自动跳过（macOS 在这种情况下访问通知中心会直接崩溃），需要通知请运行打包后的 `.app`。
- `--demo` 只把演示数据放在内存里，不会写入数据文件。
- `./scripts/build_app.sh` 会自动生成应用图标、组装 `.app`、做 ad-hoc 签名，并执行一次自检。

## 界面说明

- **状态栏图标**：外圈是今日工时进度环，中心实心圆点表示正在上班，空心表示不在上班，达标后变成对勾；右侧可选显示实时时长。
- **快速面板**：日期与状态、进度环卡片（今日目标 / 剩余 / 状态）、上班·下班·撤销下班按钮、今日打卡记录、今日目标快捷设置、页脚（分析 / 设置 / 更新节假日 / 退出）。
- **修正首次打卡**：面板“今日记录”旁的小按钮可把当天第一次打卡调整成实际上班时间。
- **工时分析**：
  - *统计*：日/周/月/季度/年切换与翻页，累计工时、目标工时、完成度、加班时长四张卡片，柱状图（达标部分渐变、加班橙色堆叠、虚线为目标），每日明细列表。
  - *节假日*：按年份查看放假与调休补班，显示数据来源与缓存时间，可手动更新。
  - *导出*：选择范围（今日/本周/本月/本季度/今年/全部），预览天数、段数与工时，导出明细或汇总 CSV。
- **设置**：工时目标、自动上班（开关 + 时间门槛）、自动下班、达标通知、节假日国家/地区与缓存、状态栏显示、Dock 图标隐藏、统计与记录时区（默认北京时间）、数据文件位置与清空。
- **Dock**：默认在 Dock 与台前调度中显示；Dock 右键可以上班/下班打卡、撤销下班、打开分析与设置。点击 Dock 图标会打开工时分析窗口。

## 项目结构

```

Sources/WorkTimeRecorder/        AppKit 界面层：状态栏、面板、分析窗口、设置窗口
  ├─ Store/AppStore.swift        状态中心：持久化、自动打卡调度、统计与导出
  ├─ Services/                   锁屏事件监听、系统通知
  └─ UI/                         主题、控件、图表绘制、各窗口控制器

Assets/                          Info.plist、应用图标（由 --render-icons 生成）
```

- `swift test`：62 个用例覆盖工时账本（多段打卡、跨天裁剪、撤销、修正首次打卡）、自动打卡规则、节假日解析与缓存、统计分桶与目标口径、CSV 生成与转义、状态文件读写与损坏恢复、北京时间时区口径与旧文件迁移。
- `WorkTimeRecorder --self-check`：构建并校验状态栏面板、分析窗口、设置窗口的布局尺寸，检查状态栏图标绘制、统计与导出链路、打卡链路、时区/时间戳口径、Dock 集成，以及“演示模式不写盘”回归。
- 打包脚本在生成 `.app` 后自动执行同一套自检。

## 已知限制

- 自动打卡依赖应用处于运行状态，应用未运行期间的事件不会被补记。
- 系统通知只在以 `.app` 形式运行时可用。
- 锁屏/解锁优先使用系统分布式通知，另有 5 秒轮询兜底；个别系统版本若都不发事件，自动打卡可能延迟。
- 暂未实现开机自启（后续可用 `SMAppService` 补充）。
- 界面使用 AppKit 实现：macOS 26 SDK 的 SwiftUI 改为宏实现，而本机只安装了 Command Line Tools（缺少 `SwiftUIMacros` 插件），SwiftUI 无法在本地编译与验证。
